# シンプルキーフレーム v2.1.0

YMM4用のキーフレームプラグインです。
位置・拡大率・回転・不透明度をキーフレームで変更できます。

## サンプル

https://github.com/user-attachments/assets/2a8d2cb6-5cd3-4071-9f4c-a6cf4716fa8e

## 導入・更新

1. プロジェクトを保存してYMM4を終了します。
2. [Release](https://github.com/CreamDevelopers/SimpleKeyframe/releases/latest)から `KeyframeStudio.ymme` をダウンロードし、ダブルクリックして導入・更新します。
3. YMM4を起動します。

手動で導入する場合は、以下の2ファイルを同じフォルダーへコピーしてください。

`KeyframeStudio.zip` も同じReleaseからダウンロードできます。

```text
YMM4/user/plugin/KeyframeStudio/KeyframeStudio.dll
YMM4/user/plugin/KeyframeStudio/0Harmony.dll
```

既存のDLLは同じ場所で更新してください。同じDLLを複数のサブフォルダーに置かないでください。

## 操作

1. タイムラインのアイテムを選択します。
2. 再生ヘッドをキーを置く位置に移動し、**K** を押します。
3. 別の位置にもKでキーを追加します。
4. キーの位置でX・Y・回転角などの数値を変更するか、プレビューで移動・回転します。
5. キー間が補間されます。キーマークはタイムラインのアイテム上に表示されます。

**Shift+K** で現在位置のキーを削除します。
文字・数値の入力中はショートカットを受け付けません。タイムラインにフォーカスを戻して操作してください。

### 右クリック

アイテムの右クリックメニューから次の操作ができます。

- キーフレームを追加（再生位置）
- キーフレームを追加（クリック位置）
- キーフレームを削除（再生位置）

複数選択時は、指定した時刻を含む、ロックされていない映像アイテムが対象です。

### 数値欄

- **◆**：現在位置にキーがあります。クリックすると削除します。
- **◇**：現在位置にキーがありません。クリックすると追加します。
- ◆/◇の右クリックで直線・イーズイン・イーズアウト・イーズインアウト・ホールドを選択します。

補間はプロパティ単位の設定です。キーの時刻はアイテム内で共通です。
最初のキーより前と最後のキーより後は端の値を保持します。

### 設定

`ツール → シンプルキーフレーム` で有効・無効と自動キーを設定できます。

自動キーがオンの場合、キー間で値を変更すると、その位置にキーを追加します。
オフの場合は既存のキーの位置で編集してください。キー間の数値欄は無効になります。

## 対象と制限

- X・Y・Z・拡大率・回転・不透明度が対象です。
- キーと値はYMM4標準の形式で `.ymmp` に保存します。
- 既存のYMM4標準キーがあるアイテムも、有効中は現在キーを編集する操作になります。
- 移動量指定・ランダム移動など、キー補間を使わないアニメーションは変換しません。
- 文字サイズや図形の縦横サイズを直接変更するプレビューのリサイズ操作は対象外です。拡大率は数値欄で編集してください。
